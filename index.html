Snorbik AI Platform

Plateforme IA locale pour développeurs — Gateway OpenAI · Ollama · Monitoring GPU · Cursor / VS Code / Codex

Démo

Gateway locale, modèles et monitoring matériel en direct

C'est quoi ?

Coder avec l'IA passe presque toujours par des API cloud. Ça coûte cher, expose le code, et dépend d'une connexion externe.

Snorbik AI Platform est une infrastructure IA installée en local qui se comporte comme une API OpenAI — les IDE utilisent des modèles locaux, les données restent sur la machine.

Ce que fait la plateforme

  • MVP v1 — Gateway locale compatible OpenAI + agents MCP
  • MVP v2 — Catalogue modèles, monitoring GPU/CPU/RAM, interface de supervision
